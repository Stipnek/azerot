# Pocket Azeroth

Pocket Azeroth — браузерная фан-игра, не связанная с Blizzard Entertainment.

The game was previously named Azerot / Азерот. The repository name, site address, save keys and stable internal identifiers remain unchanged. The in-world place name Azeroth / Азерот is not an application-brand reference.

## Start here: contributors and AI assistants

1. Record the branch and current commit before starting. Read files from that revision; do not reconstruct the project from chat history.
2. Start with the [development guide](DEVELOPMENT.md), including its release section. Other sections may contain earlier agreements or historical status; verify their applicability against the current source.
3. Read the documents for the relevant system. Check each document's status and inspected revision: a proposal, an approved requirement, and implemented behavior are different things.
4. Before changing code, inspect its callers, data sources, build integration, and related tests.
5. If a file was retrieved only partially, record that limitation and obtain the missing content before treating its review as complete.
6. The presence of code does not establish successful tests or deployment. Report what was read, changed, tested, and published separately.

A complete source map and documentation catalog are still being prepared. This section is an initial reading guide, not a complete or verified map of the project.
