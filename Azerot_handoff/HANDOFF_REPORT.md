# Azerot — пакет изменений UI review («Город» + подготовка Мёртвых копей)

Источник: `Azerot-review-source.zip` (445 записей, 434 файла). Это итоговый проект после переделки. GitHub не изменялся, ничего не публиковалось.

## 1. Главное ограничение

Исходного архива базовой ветки (`10337cd359d3c00ad58ed832f310892c4493d612`) у меня нет, в ZIP нет `.git`. **Точное пофайловое сравнение «до/после» выполнить нельзя.** Подтвердить, что итоговый ZIP построен именно от `10337cd`, тоже нельзя.

Поэтому изменения определены двумя способами разной силы.

**Входы сборки (шаблон, CSS, скрипты, `*.edits.json`, ассеты) — подтверждено сборкой.**
- Итоговый проект собирается в 30 331 826 байт, SHA-256 `f9a991ff…6f0e`. Это совпадает с «Review build» в `docs/ui-review-register.md`.
- Убраны 2 правки из `src/template.html`, удалены `src/styles-29.css` и два `*.review-ui.edits.json`. Получилось 30 313 537 байт, SHA-256 `b3b58be2…6be46f`. Это байт-в-байт совпадает с «Baseline build» из того же реестра.
- Откатанный `src/template.html` байт-в-байт совпадает с `template.txt` из более раннего снимка `30b31a11` в файлах проекта. Это независимое подтверждение для шаблона.
- Оговорка: хеш базовой сборки записан автором переделки в реестре, а не получен из исходного архива.

**Файлы вне сборки (тесты, документы) — сравнением НЕ подтверждено.** Признаки:
- В ZIP 425 файлов имеют одинаковое время 12:40, а 9 файлов — 15:39–15:44.
- Дополнительно учтены ссылки из неизменённых workflow и записи CHANGELOG.
- Статус «добавлен/изменён» для этих файлов — вывод, а не результат сравнения.
