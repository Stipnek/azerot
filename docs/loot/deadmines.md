# Мёртвые копи: лут

## Статус
Интеграция в рабочую ветку, не публикация. Характеристики и названия предметов авторские тестовые, не точный каталог Classic. Готовность к слиянию определяется CI и браузерной проверкой, не этим документом.

## Каталог
Источник истины: функция dmCatalogue в script-06.zzzzzzzz-deadmines-loot.edits.json. 21 предмет: по три профиля (сила, ловкость, интеллект) для семи боссов. ID = 921000 + номер босса с нуля * 10 + номер профиля с нуля. Требование: 17 уровень. Броня = 12 + 2 * номер босса; выносливость = 3 + floor(номер босса / 3); основная характеристика = 4 + floor(номер босса / 2); продажа = 25 + 5 * номер босса медных. Это стартовые значения для проверки механики, не финальный баланс.

Куки выбирается добровольно перед Ван Клифом. Дополнительного отдыха нет. Главный герой сохраняет шесть существующих слотов; руки этот каталог не заполняет. Аксессуары соратников вне патча.

## Выдача
За живую победу — одна подходящая по классу и основной характеристике вещь в сумку. Автоматически не надевается. Повторная обработка победы не даёт предмет и опыт второй раз; новый забег допускает дубликаты. При переполнении количества или ошибке сохранения показывается предупреждение.

Между боями можно открыть существующую сумку. Автопереход приостанавливается до следующего боя. Смена вещей не восстанавливает здоровье и ману; действуют прежние правила переноса ресурсов и отдыха. Симулированный пропуск по-прежнему показывает справочные трофеи, не выдаёт новые предметы.

## Проверки
Новый CI проверяет применение всех правок, синтаксис, обработчики с настоящим Battle и сборку. DOM и сохранение в модульных тестах имитируются. Полный браузерный проход, перезагрузка сохранения и окончательный баланс требуют отдельной проверки. Не считать патч готовым к слиянию до результатов.
