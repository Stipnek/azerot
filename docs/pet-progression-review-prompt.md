## Задача

Ревизия и план реализации прогрессии питомцев охотника и чернокнижника (OPEN-WORK **PET-01**, решения владельца **2026-11-28**). Сначала **только чтение и отчёт с планом** (фаза 1–2 CLAUDE.md); код — после одобрения владельца, по одному пункту на ветку.

## Что решил владелец (обязательно к исполнению)

1. **Питомцы охотника открываются так же, как демоны чернокнижника** — автоматически по своему уровню, по таблице `docs/combat-pets-2026-11-21.md`: Черепаха 10, Кошка 20, Волк 30, Сова 40 (чернокнижник: Бес 1, Демон Бездны 10, Суккуб 20, Охотник Скверны 30). Приручения и кормления нет. До 10 ур. у охотника питомца нет. После открытия нет режима «без питомца». Один активный питомец, у каждого своё состояние, смена только вне боя.
2. **«Мёртвой зоны» охотника (Classic: 5–8 ярдов) не делать.**
3. **Ориентир — WoW Classic:** по умолчанию как в Classic; отличия явно помечать как адаптацию для автобоя. Таблица PET-01 — уже утверждённая адаптация (в Classic приручают любого зверя на 10).

## Известные факты (проверь сам в эффективном коде, не верь на слово)

Эффективный код = база `src/scripts/script-NN.txt` + все `*.edits.json` по порядку имён + core; собирается `node -e "require('./scripts/lib_engine_load.cjs').source('src/scripts/script-05.txt')"` (движок) и `...script-06.txt` (интерфейс).

- Движок: в `PETS` есть только `imp, voidwalker, felhunter, succubus, wolf` — нет черепахи, кошки, совы. Движок принимает любого питомца на любом уровне.
- Интерфейс: `PET_SELECTION_LEVEL = 10` открывает сразу всех демонов; у охотника волк с 1 ур. (`petFor`: «До 10 уровня волк») и кнопка «Без питомца» с 10 ур. — оба пункта против документа.
- Правило «Сближение» (PLAY-19, движок `enemyApproach`): если в отряде только дальники и нет живого питомца ближнего боя, враг ближнего боя тратит первый ход на подход. С 2026-11-28 бес считается дальним питомцем (`RANGED_PETS = { imp: true }`) и правило не отменяет; Выживание охотника сейчас считается ближником (автоатака «Удар»).
- Баланс (замеры 2026-11-28, `scripts/lib_class_probe.cjs`, соло против двух врагов своего уровня, цель BAL-04/05 — около половины ХП): охотник 1–9 ур. с волком теряет 29–52% ХП, **без питомца 63–79%** (слишком тяжело); чернокнижник 1–9 ур. с бесом после правки «Сближения» теряет **8–19%** (слишком легко; раньше 15–37%). Учебные заклинания кастеров с 2026-11-28 умножены на 1,2 (компенсация за убранный удар посохом) — учти в замерах.
- Classic (по поиску, Wowhead/warcraft.wiki.gg напрямую из этого окружения не открывались — перепроверь, если у тебя есть доступ): охотник получает первого питомца на 10 ур. квестом; до этого стреляет и бьёт Ударом ящера вблизи; Контузящий выстрел с 8, Подрезать крылья с 12. Выживание в Classic — дальний спек (лук), ближний бой — только таланты. Бес у чернокнижника с начала игры, дальний, хрупкий, без провокации; Демон Бездны с 10 по квесту, умеет провоцировать.
