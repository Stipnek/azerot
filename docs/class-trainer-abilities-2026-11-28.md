# CLASS-01: умения как у тренера Classic до 30 уровня — проект на одобрение

Статус: **предложение (proposed), код не менялся.** Ревизия: ветка `claude/pocket-azeroth-continue-50hrxf` после `4d06d22`. Основание: решение владельца 2026-11-28 (OPEN-WORK CLASS-01, AI-HANDOFF «Owner direction 2026-11-28» п. 1–5).

**Источник списков.** Уровни тренера ниже — по Classic 1.12, записаны по памяти и **ещё не сверены** с базой (classicdb / Wowhead Classic). Перед кодом каждого класса сверю его список по базе и исправлю этот документ; расхождения отмечу.

## 1. Правила (из решения владельца)

1. Учебных наборов больше нет. Каждый класс с 1 уровня учит умения тренера Classic **по своему уровню**, одинаково для всех спеков.
2. Выученное не пропадает никогда, в том числе на 15 уровне.
3. Спек = роль + дерево талантов (+ аура лидера). Умения, которые в Classic давал талант, — только через талант (как у воина сейчас). Спутники берут их по своей линии талантов.
4. Пассивки спека — только из талантов, как в Classic (Толстая шкура, Глубокие раны…). Отдельных «пассивок спека с 15/30» нет; спутник получает пассивку, когда его линия талантов доходит до этого ряда.
5. Лимита на число умений нет: автобой сам выбирает.
6. Отступления от Classic только там, где этого требует наш формат, с пометкой **«адаптация»**.

## 2. Что не переносим (общие правила адаптации)

В автобое нет перемещения, экипировки по ходу боя, торговли и мира вне боя. Поэтому **не переносятся** (никаких кнопок, никаких описаний):
- небоевые умения: еда/вода, отслеживание, слежение за зверями, взлом, карманная кража, обнаружение, водное/походное облик, Око Килрогга, призыв, создание камней (кроме тех, что бой использует, см. вопрос В4), воскрешение вне боя;
- чистые «поддержки вне боя» (Интеллект, Стойкость, Знак дикой природы, Благословения) → **адаптация:** действуют как бафф на весь бой с начала боя, без кнопки (как сейчас «обереги»); показываются в «Герое» списком «действует весь бой»;
- стойки воина и формы друида → **адаптация:** не умения, а состояние спека (воин Защиты — в оборонительной стойке, Медведь — в облике медведя и т. д.); умения, требующие другой стойки, ИИ использует без переключения (как сейчас);
- снятие эффектов (Рассеивание, Снятие проклятия, Очищение) — пока нет вражеских дебаффов, которые этим снимаются; **вопрос В3**.

Умения с контролем (страх, сон, превращение, ловушки) — переносим только если ИИ может их осмысленно применить в бою 3 на 3; иначе — в «не переносим» с пометкой.

## 4. Что меняется в ИИ

- ИИ спека выбирает из **всех** выученных умений по приоритету роли: танк (угроза, защита), лекарь (лечение, мана), боец (урон). Умения ниже по приоритету используются, когда верхние на перезарядке или нет ресурса.
- Каждое умение набора должно применяться хотя бы в одном из контекстов `test_class_rules.cjs` (соло, долгий бой, группа, тяжёлый бой); иначе — либо правим приоритет, либо умение не переносим (честно, а не «мёртвым грузом»).
- Учебный ИИ (`neutral_training`) исчезает: до 15 герой воюет ИИ своего класса без талантов (роль — «боец», кроме явного лечения у жреца/паладина/друида при низком ХП).
- Баффы «на весь бой» — без кнопки и без хода.
