## Правила

- Основа: Vanilla / Classic Era, без Cataclysm, SoD и последующих дополнений.
- Разделяем оригинал, предложения адаптации и нерешённые вопросы.
- Для каждой цепочки фиксируем получение, цели, выполнение, сдачу, координаты и источники.
- ≈ обозначает приблизительную позицию или область, не точный спавн. Координаты оригинальной зоны не являются координатами авторской иллюстрации.
- Межзональные продолжения отделяем; для одной открытой зоны используем одну карту. Дома, трюмы и пещеры работают через события.
- Отдельно проверяем фракцию, prerequisites и актуальную реализацию проекта. Наличие в каталоге не означает наличие в игре.
- Не назначаем награды и баланс без данных экономики. Не вводим классовые и профессиональные требования в общий путь.
- Новые локации добавляем отдельными документами и ссылками в эту таблицу. Готовность фиксируется после принятия пользователем.
