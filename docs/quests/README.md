## Правила

- Основа — Vanilla / Classic Era, не Cataclysm, SoD или следующие дополнения.
- Сейчас подробно разрабатываем Альянс. Для Орды сохраняем краткие референсы и места на общей карте; фракционные журналы не смешиваем.
- Одна открытая зона — одна основная карта для обеих фракций. Не удаляем каноническое место только из-за отсутствия там альянсового задания.
- Разделяем оригинал, адаптацию и нерешённые вопросы. Получение, конкретные цели, выполнение, сдача и источники фиксируются отдельно.
- ≈ — приблизительная позиция. Координаты исходной зоны не равны координатам авторской иллюстрации; маркировка привязывается после утверждения арта.
- Межзональные путешествия сохраняем как в Classic. Не требуем искусственного финального босса или закрытой кампании каждой зоны. Отмечаем, где проходит каждый этап.
- Дома, трюмы и пещеры — события без дополнительных навигационных карт. Пустые столичные доставки можно сокращать явно обозначенной адаптацией.
- Перед внедрением сверять текущие данные игры, prerequisites и фракцию; не дублировать имеющиеся задания. Наличие документа не означает готовую реализацию.
- Не назначаем награды и баланс без экономики проекта. Не добавляем профессии как обязательный общий путь.
- Арт: сначала чистая карта в стиле существующего Элвинна; затем существующая общая рамка отдельным слоем. Без текста и квестовых меток в изображении.
- Новые зоны добавляем отдельными файлами. Слово «принято» фиксирует готовность дизайна, не факт внедрения.
