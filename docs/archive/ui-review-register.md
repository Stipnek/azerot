## Build and preview facts

- All six named source documents were present. The current request supersedes the older instruction to keep a text close button in the service drawer. Historical production references in DEVELOPMENT and CHAT-AUDIT differ; no production action was performed and no live comparison is claimed.
- Baseline `scripts/build_game.py`: 30,313,537 bytes, SHA-256 `b3b58be2b85f03834b2a878b05a2b767ab57bd202e3000ca97b4a905076be46f`. `--check-original` reported a byte difference before any edit; it is the frozen extraction/assembler round-trip check, not a requirement that current gameplay match archived root parts. No checks were disabled.
- Review build: 30,331,826 bytes, SHA-256 `f9a991ffddc5f937329b067ece90730f48e5ad761170a722f691bb485b552f0e`. Existing strict source manifest check validated 21 manifests and 118 edits; 13 Node suites, 5 coin tests, and Chromium lobby and party/quest regressions ran. Browser review ran in isolated contexts and reported no uncaught JavaScript errors in the checked cases. The screenshots are direct Chromium captures, not generated imagery.
- The ZIP lacks the three original coin PNGs. The unmodified builder fetched pinned raw files over HTTPS from `raw.githubusercontent.com`, verified PNG format, exact length and Git blob SHA-1, and embedded them. No GitHub account connection, repository change or release. The mirror is not a license grant, so no separate new copies of the third-party coin assets are vendored in the source archive; the build embeds them as before. A clean source build may require that same network fetch.
- Chromium observed `fonts.googleapis.com`, `fonts.gstatic.com`, and `wow.zamimg.com`. Existing source also references third-party art/reference URLs not exercised in this run. No new runtime hosts were introduced. Complete game operation with networking blocked is not claimed.
- The preview server listened on loopback only. The exported HTML is the game build, not a preview website. Local files and the browser test server have a different origin from any published game. Isolated synthetic saves were backed up before the browser scenarios and the backups are not shipped.

## Repeating the added browser test (for maintainers)

Use Node with `playwright` and `@sparticuz/chromium` available and run `node scripts/browser_ui_review.cjs` while the local build is served on `http://127.0.0.1:8765/`. Override `GAME_URL` / `SHOTS` if needed. The test uses isolated browser contexts, leaves screenshots in `results/ui-review`, and keeps synthetic backup data there; do not publish that directory.
