# Wowhead ability icons

World of Warcraft artwork, copyright Blizzard Entertainment, Inc. All rights reserved. No licence is granted.

Unchanged 56x56 copies of `https://wow.zamimg.com/images/wow/icons/large/<name>.jpg`, downloaded 2026-11-28 so the game
does not load icons from Wowhead at runtime (owner, 2026-11-28). `manifest.json` lists each file's size and SHA-256.
`scripts/icon_assets.py` embeds them into the build; see its header for adding a new icon.
