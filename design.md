# Дизайн и статус реализации

Обновлено: 19 ноября 2026, по договорённостям в чате. Это фиксация решений, а не подтверждение успешной публикации.

## Панель карты
- На месте ряда сервисных кнопок — одна кнопка «Меню». Остальные действия доступны внутри диалога.
- Переносятся исходные кнопки, сохраняются их обработчики и disabled-состояние. После перерисовки карты меню собирается заново без дубликатов.
- Отдельной кнопки запуска Мёртвых копей среди сервисов нет.
- Не объединять с этой панелью мировую навигацию и другие не относящиеся к ней элементы без отдельного согласования.

## Вход в подземелье
- Вход в Мёртвые копи расположен на карте Западного края; нажатие открывает подготовку, но не запускает бой сразу.
- Подготовка содержит состав отряда, боссов, добычу и отдельное действие начала забега.
- Общий образ данжей: каменно-деревянный немного заваленный вход, паутина и небольшой факел; прозрачный фон, нейтральная палитра для светлых городских и тёмных лесных карт.
- Мёртвые копи: проём влево. Для будущей Тюрьмы — зеркально вправо. Тюрьму сейчас не реализуем.
- Стиль сверять с присланной пользователем рисованной картой: миниатюрная архитектура, вид сверху под углом, матовая живописная фактура.
- Утверждённый ресурс: src/assets/dungeon-entrance.svg; внутри растровая миниатюра, а не векторная перерисовка. Подключение в исходниках: 553ef96. Визуальная проверка на опубликованной карте не подтверждена.

## Лут Мёртвых копей
- Отдельные небольшие наборы вещей у боссов; предмет после победы идёт в сумку с характеристиками.
- Надевание доступно между боями. Повторная обработка одной победы не выдаёт добычу повторно.
- Подробности: docs/loot/deadmines.md. Наличие реализации в репозитории не считать доказательством работоспособности live-версии.

## Проверка и публикация
- Различать: подготовлено, записано в main, тесты пройдены, опубликовано, визуально проверено.
- Автопубликация настроена после проверок; фактический результат GitHub Actions и текущий live-коммит на момент этой записи неизвестны.
- test_service_panel.cjs проверяет синтаксис и статические инварианты патча, но не заменяет браузерный тест.
- Приёмка в браузере ещё требуется: одна сервисная кнопка, открытие/закрытие меню и Escape, работа каждого исходного действия, повторные перерисовки без дубликатов, отсутствие сервисного запуска данжа, открытие подготовки с карты, вид иконки на мобильном и широком экране.
- Слияние — после завершения сегодняшней работы; эта запись его не выполняет.
