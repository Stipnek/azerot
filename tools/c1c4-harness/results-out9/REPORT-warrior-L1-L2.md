## Метод (только штатные действия)
- Чистый профиль браузера; перед стартом harness проверяет, что localStorage пуст.
- Штатный путь: экран входа `#pa-enter` → раса «Человек» → класс «Воин» → имя «Тествоин» → «Создать героя» → `#sel-enter`.
- Цикл: за каждый шаг выбирается одно действие (порядок приоритета):
  1. экран итогов боя → «На карту»;
  2. таверна → призыв/«Пропустить»/закрыть;
  3. пустой слот отряда (если нанятый спутник есть, а в отряде один герой) → выбор спутника в окне подбора;
  4. `#q-turn` / `#q-fight` / `#q-party` / `#pick-ok` / `#q-go` / `#q-take` / `#skipbtn`;
  5. список квестов локации → первый квест;
  6. маркеры и журнал: сначала сдача, потом активные квесты, потом доступные.
- Бой идёт сам (автобой) на скорости x1; по ходу боя harness ничего не нажимает. Отладочные элементы запрещены и проверяются assert'ом:
  `lv-plus, lv-minus, tav-give, chk-allq, chk-allspecs, chk-amb, chk-test, chk-comp, chk-auto`.
- Состояние только читается из `localStorage['azeroth-arms-hero-v1']` (JSON.parse); в localStorage harness не пишет.
- Стоп: достигнут 2-й уровень или 25 итераций подряд без изменений сохранения (тупик).

## Наблюдения (воспроизводятся этим прогоном; причины не установлены)
1. **Спутник не участвует в обычных квестовых боях.** Во всех четырёх боях после обучения итог «В живых: 1 из 1», хотя в отряде двое.
   Урон наносил только воин. В бою tutorial57_team спутник был: «2 из 2».
   Это может быть задумано (размер квеста или настройка), может быть дефектом — требует решения. Прямо влияет на C4 (прогрессию спутников).
2. **Специализация спутника отображается по-разному.** В таверне жрица показана как «Жрец · Свет», в коллекции сохранено `sp:'holy'`.
   В окне подбора и в отряде она же отображается как «Тьма», с умениями Тьмы.
3. **Когда начисляется XP.** «Опыт: N» в итогах боя попадает в `hxp.me` только при сдаче квеста (+10, +20, +105, +100, +100, +110). Двойного начисления не замечено.
4. Раса бесплатного спутника меняется от прогона к прогону (ночной эльф, дварф): призыв случайный. Итог (уровень 2, XP 445, деньги 430, камни 42) совпал в трёх прогонах до L2: out7, out8, out9.

## Обходы UI и допущения автоматизации
- Клики Playwright по селекторам, а не касания: мобильные жесты, положение пальца и перекрытие на малых экранах не проверялись.
- Анимации не дожидаются глазами: пауза 0,7 с после клика. Боевая анимация на x1 идёт, но не оценивается.
- Чтение localStorage — только для журнала, на выбор действий не влияет. Исключение — правило выбора спутника: «в отряде < 2 и коллекция не пуста».
- Порядок выбора квестов задаёт harness (первый в списке), а не игрок. Групповой квест и «Налёт» не брались, потому что 2-й уровень уже был достигнут.
- Проба L2 через `probe_saved.py` перезагружает страницу с сохранением прогона: это не выдача, а повторное открытие того же состояния.
- Не проверялись: звук, настройки, старые сохранения, основной index.html, портретная или мобильная раскладка, офлайн.
