# Подсказка перехода между зонами
Дополнение к docs/design.md, 19 ноября 2026.

## Договорённость
Подсвечивается сама существующая кнопка «Карта мира», без добавления кнопок и без автоматического перемещения героя.

Подсказка нужна, если:
- Доступный взятый квест требует выполнения или сдачи в другой реализованной зоне.
- В текущей зоне героя нет доступных действий по заданиям, но в другой реализованной зоне они есть.

Учитываются текущий этап задания, prerequisites и доступность через qVisible; завершённые задания исключаются, задания на перезарядке сами подсказку не включают. Проверяется физическая зона героя, не просто просматриваемая карта. Зоны без реализованного входа исключаются.

## Отображение
Мягкая золотистая пульсация с периодом 1,8 секунды. При prefers-reduced-motion — неподвижная подсветка. Причина и названия зон доступны в title и aria-label. При следующей перерисовке карты подсветка исчезает, если оснований больше нет. Открытие карты само по себе не устраняет причину подсказки.

## Статус проверки
Девять изолированных сценариев логики проверены локально в Node. Добавлен повторяемый тест scripts/test_world_travel_hint.cjs для общего прогона test_*.cjs. Это не подтверждает прохождение GitHub Actions, публикацию, внешний вид или работу обновлений в браузере: эти проверки ещё требуются.
